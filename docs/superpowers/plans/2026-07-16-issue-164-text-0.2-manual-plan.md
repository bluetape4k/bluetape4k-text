# bluetape4k-text 0.2 매뉴얼 구현 계획

> **Agentic worker 대상:** 필수 sub-skill은 `superpowers:subagent-driven-development`(권장) 또는 `superpowers:executing-plans`이다. 이 계획은 작업 단위로 구현하며, 진행 추적에는 checkbox(`- [ ]`) 문법을 사용한다.

**목표:** 안정 배포본 0.2.1을 근거로 삼는 영문·국문 0.2 매뉴얼, 다크 스타일 다이어그램, 기계 검증 가능한 매니페스트를 `docs/manual/`에 구축한다.

**아키텍처:** `docs/manual/manifest.yaml`을 문서·모듈·자산·릴리스 출처의 기준으로 삼고, Ruby 계약 검증기가 릴리스 트리와 로컬 문서 트리를 함께 확인한다. 영문 문서를 기술 내용의 초안으로 작성한 뒤 한국어를 자연스러운 문장으로 다시 구성하되, 경로·섹션·예제·근거의 동등성은 자동 검사한다. 다이어그램은 하나의 Ruby 렌더러에서 SVG를 만들고 PNG로 변환하며 자동 검사와 전체 크기 눈 검수를 모두 거친다.

**기술 스택:** Markdown, YAML, JSON, Ruby 표준 라이브러리와 Minitest, REXML, CairoSVG 또는 동등한 SVG→PNG 렌더러, Git/GitHub CLI

- [ ] **단계 3: 최소 계약 구현 작성**

`ManualContract`는 저장소 루트와 매니페스트 경로를 주입받고 `validate!`에서 오류를 모아 한 번에 보고한다. 외부 URL은 네트워크로 확인하지 않고, 상대 링크와 GitHub 소스 ref 형식만 검사한다.

```ruby
class ManualContract
  class Violation < StandardError; end

  def initialize(root:, manifest:)
    @root = Pathname(root).expand_path
    @manifest_path = Pathname(manifest).expand_path
  end

  def validate!
    errors = []
    validate_locales(errors)
    validate_documents(errors)
    validate_links(errors)
    validate_source_refs(errors)
    raise Violation, errors.join("\n") unless errors.empty?
    true
  end
end
```
