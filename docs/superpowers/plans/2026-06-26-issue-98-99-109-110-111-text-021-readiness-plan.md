# 0.2.1 Text 준비성 구현 계획

> **Agentic worker 대상:** 필수 sub-skill은 `superpowers:subagent-driven-development`(권장) 또는 `superpowers:executing-plans`이다. 이 계획은 task 단위로 구현하며, 진행 추적을 위해 checkbox(`- [ ]`) 문법을 사용한다.

**목표:** Lingua option 테스트, 실행 가능한 예제, 안전 문서, CI/Nightly compile coverage를 추가해 0.2.1 준비성 issue를 닫는다.

**아키텍처:** `examples/` 아래에 publish하지 않는 Gradle 예제 모듈 세 개를 추가한다. Production API는 변경하지 않고, 테스트와 예제는 현재 public API를 실행한다. 루트 build logic은 예제를 publication과 coverage aggregation에서 제외하되 CI/Nightly에서는 compile하고 test한다.

**기술 스택:** Kotlin/JVM 2.3, Gradle 9.6, JUnit 5, bluetape4k-assertions, Kotlin coroutines Flow, Lingua, Kuromoji, bluetape4k tokenizer/search API.

- [ ] **단계 3: 예제를 publishing에서 제외**

첫 번째 `subprojects` block을 업데이트한다.

```kotlin
subprojects {
    if (isNonPublishedModule()) {
        return@subprojects
    }
    apply(plugin = "com.gradleup.nmcp")
    // existing NMCP configuration remains unchanged
}
```

두 번째 `subprojects` block의 plugin 적용을 업데이트해 publish 가능한 모듈은 기존 library plugin set을 유지하고, 예제는 Kotlin/JVM application 테스트에 필요한 가벼운 plugin만 받게 한다.

```kotlin
val isNonPublished = isNonPublishedModule()
if (isNonPublished) {
    apply {
        plugin<JavaLibraryPlugin>()
        plugin("org.jetbrains.kotlin.jvm")
        plugin("application")
        plugin("com.adarshr.test-logger")
    }
} else {
    apply {
        plugin<JavaLibraryPlugin>()
        plugin("org.jetbrains.kotlin.jvm")
        plugin("org.jetbrains.kotlinx.atomicfu")
        plugin("org.jetbrains.kotlinx.kover")
        plugin("maven-publish")
        plugin("signing")
        plugin("io.spring.dependency-management")
        plugin("org.jetbrains.dokka")
        plugin("com.adarshr.test-logger")
    }
}
```

각 `examples:*` 모듈 `build.gradle.kts`는 실행 entrypoint를 설정해야 한다.

```kotlin
application {
    mainClass.set("<fully.qualified.MainKt>")
}
```

이 계획의 run-smoke gate는 해당 `mainClass` 선언에 의존한다.

- [ ] **단계 4: 예제를 aggregation에서 제외**

`publishing {}`과 `configurePublishingSigning("BluetapeText")` 섹션을 `if (!isNonPublished) { ... }` 안에 감싸 publish하지 않는 예제가 `publishing` extension을 전혀 요구하지 않게 한다.

Aggregation을 업데이트한다.

```kotlin
dependencies {
    subprojects
        .filterNot { it.isNonPublishedModule() }
        .forEach { add("nmcpAggregation", project(it.path)) }
}

dependencies {
    subprojects
        .filter { it.name != "bluetape4k-text-bom" && !it.isNonPublishedModule() }
        .forEach { sub -> add("kover", project(sub.path)) }
}
```
