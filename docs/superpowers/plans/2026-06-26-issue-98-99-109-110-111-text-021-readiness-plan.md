# 0.2.1 Text Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the 0.2.1 readiness issues by adding Lingua option tests, runnable examples, safety documentation, and CI/Nightly compile coverage.

**Architecture:** Add three non-published Gradle example modules under `examples/`. Keep production APIs unchanged; tests and examples exercise current public APIs. Root build logic excludes examples from publication and coverage aggregation while CI/Nightly compile and test them.

**Tech Stack:** Kotlin/JVM 2.3, Gradle 9.6, JUnit 5, bluetape4k-assertions, Kotlin coroutines Flow, Lingua, Kuromoji, bluetape4k tokenizer/search APIs.

- [ ] **Step 3: Exclude examples from publishing**

```kotlin
subprojects {
    if (isNonPublishedModule()) {
        return@subprojects
    }
    apply(plugin = "com.gradleup.nmcp")
    // existing NMCP configuration remains unchanged
}
```

Update plugin application in the second `subprojects` block so publishable
modules keep the existing library plugin set, while examples get only the
lightweight plugins needed for Kotlin/JVM application tests:

```kotlin
val isNonPublished = isNonPublishedModule()
if (isNonPublished) {
    apply {
        plugin<JavaLibraryPlugin>()
        plugin("org.jetbrains.kotlin.jvm")
        plugin("application")
        plugin("com.adarshr.test-logger")
    }
} else {
    apply {
        plugin<JavaLibraryPlugin>()
        plugin("org.jetbrains.kotlin.jvm")
        plugin("org.jetbrains.kotlinx.atomicfu")
        plugin("org.jetbrains.kotlinx.kover")
        plugin("maven-publish")
        plugin("signing")
        plugin("io.spring.dependency-management")
        plugin("org.jetbrains.dokka")
        plugin("com.adarshr.test-logger")
    }
}
```

Each `examples:*` module `build.gradle.kts` must set an executable entrypoint:

```kotlin
application {
    mainClass.set("<fully.qualified.MainKt>")
}
```

The run-smoke gates in this plan depend on those `mainClass` declarations.

- [ ] **Step 4: Exclude examples from aggregation**

Wrap the `publishing {}` and `configurePublishingSigning("BluetapeText")`

Update aggregation:

    subprojects
        .filter { it.name != "bluetape4k-text-bom" && !it.isNonPublishedModule() }
