## #42 — KoreanChunker 성능 개선

**문제**:
1. `chunksBuf.all { cm.disjoint(it) }` — O(n²): 모든 기존 청크와 비교
2. `fillInUnmatched`에서 `add(0, ...)` — O(n) prepend, 마지막에 `.reversed()`

**수정**:
1. `java.util.TreeMap<Int, ChunkMatch>` 사용 → `floorEntry`/`ceilingEntry`로 이웃만 검사 → O(log n) per check
2. `fillInUnmatched`: `add(...)` (append) + `.reversed()` 제거 → O(1) per add

**주의**: `findAllPatterns`의 `add(0, ...)` 은 기존 테스트가 역순을 기대하므로 유지.

## #43 — NounPhraseExtractor CopyOnWriteArrayList 제거

**문제**: 단일 스레드 로컬 누산기에 `CopyOnWriteArrayList` 사용 → add마다 전체 배열 복사 (O(n²))

**수정**: `mutableListOf()` (ArrayList) 로 교체. import도 제거.

## #47 — `catch (e: Throwable)` 분리

**문제**: `Throwable` catch는 `OutOfMemoryError`, `StackOverflowError` 등 JVM fatal error를 삼킴

**수정**:
```kotlin
} catch (e: Error) {
    log.error(e) { "..." }
    throw e  // 항상 재던짐
} catch (e: Exception) {
    // 기존 처리
}
```

**적용**: KoreanBlockwordProcessor.findBlockwords, maskBlockwords
