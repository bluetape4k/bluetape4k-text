# Catalog Ref 2026-05-25-01

## 배경

공유 `bluetape4k-dependencies` catalog가 ASM, AWS Kotlin SDK, Apache Fory dependency
update를 받았다.

## 결정

기본 `bluetape4kDependenciesCatalogRef`를 `develop`을 따라가게 두지 말고
`catalog/2026-05-25-01`로 pin한다.

## 결과

Gradle settings는 기본적으로 release-train catalog를 가져오며,
`bluetape4kDependenciesCatalogRef` 또는 `BLUETAPE4K_DEPENDENCIES_CATALOG_REF`로 override할
수 있다.

Snapshot publish workflow는 이제 `develop`을 강제하지 않고 dispatch된 ref를 checkout한다.
따라서 branch-gated snapshot train validation은 Nightly를 통과한 것과 같은 catalog-pinned
source를 publish한다.

## 검증

- Settings file을 `catalog/2026-05-25-01`로 업데이트했다.
- `./gradlew compileTestKotlin --refresh-dependencies --console=plain -PsnapshotVersion=-SNAPSHOT`
- `actionlint .github/workflows/publish-snapshot.yml`

## 향후 guard

Coordinated dependency train update에는 날짜가 붙은 catalog tag를 사용한다.
Manually dispatched snapshot publish workflow에서 `develop` checkout을 강제하지 않는다.
Dispatch ref를 사용해 validation과 publication이 같은 source tree를 사용하게 한다.
