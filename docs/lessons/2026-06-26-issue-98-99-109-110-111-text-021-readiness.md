# Text 0.2.1 Readiness Lessons

## 배경

0.2.1 milestone은 릴리스 준비 전에 example, 안전 문서, 선별 Lingua coverage가
필요했다. 저장소에는 `examples` module이 없었고 현재 development line은 이미
`0.3.0`이었으므로, stable release 작업에는 명확한 경계가 필요했다.

## 결정

- Example은 `examples/` 아래의 non-published Gradle application module로 둔다.
- Example은 NMCP, signing, Maven publication, Dokka, Kover aggregation에서 제외한다.
- Web-server dependency를 추가하지 않고 runnable console example을 사용한다.
- Tokenizer web-service 동작은 adapter guidance로 문서화한다. 빈 input은 400에
  mapping하고, oversized input은 413에 mapping하며, error body에는 length metadata만 담는다.
- Readiness change는 `[Unreleased]` 아래에 기록한다. 날짜가 붙은 0.2.1 release note는
  명시적인 릴리스 준비 작업에 남겨 둔다.

## 검증

- Examples `test` and `run`: PASS
- Lingua builder targeted tests: PASS
- `build -x test`: PASS
- `projects`: PASS
- `actionlint`: PASS
- README stale-version and public audit wording grep checks: PASS
- Examples task listings: no publish/sign/NMCP/Kover tasks

## 향후 지침

이 저장소에 example을 추가할 때는 먼저 root `subprojects` block을 확인한다. Version 없는
dependency는 published module의 dependency management에 의존하므로, non-published
example에는 명시적인 platform dependency나 그에 준하는 version management가 필요하다. 별도
policy decision이 바뀌지 않는 한 example은 publication과 coverage aggregation에서 제외한다.
