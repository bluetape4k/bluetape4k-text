# #334 — 불변 사전 공개 뷰의 재사용

불변성 보강을 위해 추가했던 깊은 복사가 반복 getter 접근에서도 수행되었다. 읽기 전용 wrapper의 깊은 복사를 제거하지 않고, 변경되지 않은 값에 대한 마지막 공개 뷰를 재사용한다.

값 객체의 동일성으로 갱신 여부를 확인해야 같은 revision 번호를 사용한 reload나 초기화 재시도에도 오래된 뷰를 재사용하지 않는다. 캐시는 사전 종류별 한 항목으로 제한한다. 반환한 뷰는 사전 변경 뒤에도 불변이어야 한다.

성능 수치와 재현 명령은 [측정 기록](../benchmarks/2026-09-08-dictionary-accessor.md)에 있다. 내부 토큰화 경로와 공개 getter를 구분해서 개선 효과를 기술한다.
